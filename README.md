# Woofly

Woofly es una aplicación web de demostración para organizar el cuidado veterinario de mascotas. Permite gestionar citas, consultar historiales médicos y administrar perfiles de mascotas desde un panel principal.

## Contenido

- `index.html`: inicio de sesión.
- `pages/`: panel, citas, historial médico y perfil.
- `css/`: estilos de la aplicación.
- `js/`: lógica de las páginas y utilidades compartidas.

## Uso

Abre `index.html` en un navegador. La aplicación está hecha con HTML, CSS y JavaScript, y guarda datos de demostración en el almacenamiento de sesión del navegador.
